# Max LED Lighting

A Java application that uses Dynamic Programming to determine the maximum number of LEDs that can be lit based on the given power source connections.

## Features

- Calculates the maximum number of LEDs that can be lit
- Uses Dynamic Programming to solve the problem efficiently
- Displays the optimal LED connections
- Provides a graphical user interface for entering and viewing results

## Technologies

- Java
- JavaFX
- Dynamic Programming

## How It Works

The program receives the number and order of LEDs and power sources, then applies a Dynamic Programming algorithm to determine the maximum number of valid connections without conflicts.

## How to Run

1. Clone or download the repository.
2. Open the project in Eclipse or another Java IDE.
3. Make sure JavaFX is configured.
4. Run the main application class.
